# Formix Desktop

**Formix Desktop** – системная утилита для мгновенной вставки текстовых шаблонов в любое приложение на вашем компьютере. По нажатию глобального хоткея открывается компактное окно с вашими пресетами – выбираете нужный, заполняете поля прямо внутри текста и вставляете результат одним кликом, куда бы ни был направлен фокус.

## ✨ Возможности

- ⚡️ **Глобальный хоткей** – настраивается через меню настроек (по умолчанию `Ctrl+F2`)
- 📍 **Умное позиционирование** – окно открывается рядом с курсором мыши и остаётся в границах экрана
- 📝 **Шаблоны с полями** – создавайте пресеты вида `Здравствуйте, {{Имя}}, как ваши дела?`, поле может встречаться в шаблоне несколько раз
- ⌨️ **Автоматизация клавиш** – вставляйте в шаблон нажатие клавиши или комбинации (например Enter или Ctrl+Enter) в любом месте текста
- 📁 **Папки** – группируйте пресеты по папкам
- 🔍 **Быстрый поиск** – мгновенная фильтрация по списку пресетов, работает и внутри папок
- 📋 **Вставка в один клик** – текст копируется в буфер и автоматически вставляется в активное приложение, корректно работает независимо от активной раскладки клавиатуры
- ⚙️ **Меню настроек** – хоткей, тема оформления, язык интерфейса, задержка вставки, автозапуск при старте системы
- 🌍 **Мультиязычность** – английский и русский интерфейс
- 💾 **Экспорт/импорт пресетов** – бэкап и перенос библиотеки пресетов через JSON-файл
- 🖥 **Системный трей** – приложение живёт в фоне



## 🛠 Технологии

- [Tauri 2.0](https://tauri.app) – Rust-ядро + системный webview
- React + TypeScript
- Tailwind CSS
- Framer Motion
- react-i18next – интернационализация
- SQLite (через `tauri-plugin-sql`) – локальное хранение пресетов, папок и настроек



## 🚀 Установка и запуск



### Требования

- [Node.js](https://nodejs.org) (LTS-версия)
- [Rust и Cargo](https://www.rust-lang.org/tools/install) (через `rustup`)
- На Windows – [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) с компонентом **Desktop development with C++**
- На Linux – системные зависимости WebKitGTK ([см. гайд Tauri](https://tauri.app/start/prerequisites/))



### Разработка

```bash
git clone https://github.com/PhantomUnk/Formix-Desktop.git
cd Formix-Desktop
npm install
npm run tauri dev
```



### Сборка релизной версии

```bash
npm run tauri build
```

Готовый установщик появится в `src-tauri/target/release/bundle`.

### Готовая сборка

Последний `.exe` доступен на странице [Releases](https://github.com/PhantomUnk/Formix-Desktop/releases).

> **Примечание:** сборка не подписана сертификатом, поэтому Windows SmartScreen может показать предупреждение при первом запуске. Нажмите «Подробнее» → «Выполнить в любом случае».
