# Formix Desktop

**Formix Desktop** — системная утилита для мгновенной вставки текстовых шаблонов в любое приложение на вашем компьютере. По нажатию глобального хоткея открывается компактное окно с вашими пресетами — выбираете нужный, заполняете поля прямо внутри текста и вставляете результат одним кликом, куда бы ни был направлен фокус.

Вдохновлено расширением Formix для браузера, но работает системно — не только в вебе, а в любом приложении на вашем ПК: почте, мессенджерах, IDE, документах.

## ✨ Возможности

- ⚡️ **Глобальный хоткей** — вызов окна из любого приложения (по умолчанию `Ctrl+F2`)
- 📍 **Умное позиционирование** — окно открывается рядом с курсором мыши
- 📝 **Шаблоны с полями** — создавайте пресеты вида `Здравствуйте, {{Имя}}, как ваши дела?`
- 🔁 **Переиспользование полей** — одно и то же поле может встречаться в шаблоне несколько раз
- 🔍 **Быстрый поиск** — мгновенная фильтрация по списку пресетов
- 📋 **Вставка в один клик** — текст копируется в буфер и автоматически вставляется в активное приложение (`Ctrl+V`), корректно работает независимо от активной раскладки клавиатуры
- 👋 **Закрытие по клику мимо** — окно прячется само, если кликнуть за его пределами, как в Spotlight/Raycast
- 🎨 **Минималистичный интерфейс** — компактное окно без лишних элементов, не отвлекает от работы
- 🖥 **Системный трей** — приложение живёт в фоне, не занимая место на панели задач

## 🛠 Технологии

- [Tauri 2.0](https://tauri.app) — Rust-ядро + системный webview
- React + TypeScript
- Tailwind CSS
- Framer Motion
- SQLite (через `tauri-plugin-sql`) — локальное хранение пресетов

## 🚀 Установка и запуск

### Требования

- [Node.js](https://nodejs.org) (LTS-версия)
- [Rust и Cargo](https://www.rust-lang.org/tools/install) (через `rustup`)
- На Windows — [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) с компонентом **Desktop development with C++**
- На Linux — системные зависимости WebKitGTK ([см. гайд Tauri](https://tauri.app/start/prerequisites/))

### Разработка

```bash
# Клонируем репозиторий
git clone https://github.com/<ваш-username>/formix-desktop.git
cd formix-desktop

# Устанавливаем зависимости
npm install

# Запускаем в режиме разработки
npm run tauri dev
```

Приложение соберётся и откроется в нативном окне. Первая сборка может занять несколько минут — Rust-часть компилируется с нуля.

### Сборка релизной версии

```bash
npm run tauri build
```

Готовый установщик появится в `src-tauri/target/release/bundle`.

### Готовая сборка

Если не хотите собирать сами — последний `.exe` доступен на странице [Releases](../../releases).

> **Примечание:** сборка не подписана сертификатом, поэтому Windows SmartScreen может показать предупреждение при первом запуске. Это ожидаемо для независимых проектов — нажмите «Подробнее» → «Выполнить в любом случае».

## ⚠️ Известные ограничения

- Хоткей пока захардкожен (`Ctrl+F2`), настройка через интерфейс появится в ближайших обновлениях.
